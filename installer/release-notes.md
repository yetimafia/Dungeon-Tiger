**Dungeon Tiger 1.0.0**: the first installable version.

- **Install:** download `DungeonTiger-Setup-1.0.0.exe` below and run it. No admin rights needed, and Node.js isn't needed either.
- **Link Note Tiger:** if Note Tiger is on the same PC, click **Link Note Tiger** when Dungeon Tiger opens. It turns on Note Tiger's connection and copies the key for you.
- **Settings:** the ⚙️ Settings button sets the Discord bot token, Note Tiger address, D&D rules and more. There's no file to edit.
- **Updates:** when a new version is out, an **⬆️ Update** button shows at the top. One click downloads and installs it, keeping your settings.
- A door icon by the clock shows it's running. Right-click it to open the window, restart, see the log, or quit.
